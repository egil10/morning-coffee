# ☕ morning-coffee

An automated daily news quiz. Every morning a GitHub Action asks Claude to read
the latest news (via web search), writes **10 multiple-choice questions**, then:

- 📧 **emails** you an HTML quiz with a **PDF** attached, and
- 🌐 **publishes** it to a website that keeps a browsable **archive** of every edition.

The whole archive lives in this repo under [`docs/`](docs/) — each day's quiz is a
folder of `index.html` + `quiz.pdf` + `quiz.json`, committed automatically.

- **Website:** https://egil10.github.io/morning-coffee/ *(after you enable Pages — see below)*
- **Design:** styled per [`BLUEPRINT.md`](BLUEPRINT.md) — off-white canvas, one teal accent, hairline cards, lowercase labels.

## ⚙️ One-time setup (do this in GitHub — ~10 minutes)

The code is done and pushed. To make the daily job actually run you must flip a
few switches **manually** in GitHub. Here is exactly what and where.

### 1. Add an Anthropic API key
The quiz is generated by Claude, so the job needs an API key.

1. Get a key at **https://console.anthropic.com/** → *API Keys* → *Create Key*.
2. In this repo: **Settings → Secrets and variables → Actions → New repository secret**.
3. Name it `ANTHROPIC_API_KEY`, paste the key, **Add secret**.

> Cost is small — roughly a few US cents per day (one Opus request + a handful of
> web searches). You can switch to a cheaper model later (step 6).

### 2. Let it send email from your Gmail
Gmail won't accept your normal password over SMTP — you need an **App Password**,
which requires 2-Step Verification.

1. Turn on 2-Step Verification: **https://myaccount.google.com/security** → *2-Step Verification*.
2. Create an App Password: **https://myaccount.google.com/apppasswords** → name it `morning-coffee` → **Create**. Google shows a **16-character password** (like `abcd efgh ijkl mnop`).
3. Back in the repo (**Settings → Secrets and variables → Actions → New repository secret**), add **two** secrets:
   - `GMAIL_ADDRESS` → `egilfure@gmail.com`
   - `GMAIL_APP_PASSWORD` → the 16-char app password (spaces don't matter)
4. *(Optional)* add `RECIPIENT` if you want it delivered somewhere other than `GMAIL_ADDRESS`.

### 3. Allow the Action to write back to the repo
The job commits each new edition into `docs/`.

- **Settings → Actions → General → Workflow permissions** → select **Read and write permissions** → **Save**.

### 4. Turn on the website (GitHub Pages)
- **Settings → Pages** → under *Build and deployment*, set **Source = Deploy from a branch**, **Branch = `main`**, **Folder = `/docs`** → **Save**.
- After the next run your site is live at **https://egil10.github.io/morning-coffee/**.

### 5. ✅ Test it now (no waiting for tomorrow)
- **Actions → Morning Coffee → Run workflow.**
  - Leave **Dry run = false** to do the *real* thing immediately (generates a quiz, emails you, commits, updates the site).
  - Or set **Dry run = true** to build a sample quiz with **no API key and no email** — it just uploads a `morning-coffee-preview` artifact you can download to eyeball the PDF/HTML. Great for checking rendering before secrets are set.

### 6. *(Optional)* knobs
Repo variables live at **Settings → Secrets and variables → Actions → Variables**:
- `MODEL` — override the Claude model (default `claude-opus-4-8`; e.g. `claude-sonnet-4-6` is cheaper).
- `SITE_BASE_URL` — only needed if you rename the repo or use a custom domain.
- **Change the time:** edit the `cron` line in [`.github/workflows/daily-quiz.yml`](.github/workflows/daily-quiz.yml). It's in **UTC** — `0 6 * * *` is 06:00 UTC (~07:00–08:00 in Oslo).

## 🧪 Run it locally

```bash
pip install -r requirements.txt
python -m playwright install chromium

python generate.py --sample      # sample quiz → HTML + PDF + index, no API, no email
python generate.py --no-email    # real quiz (needs ANTHROPIC_API_KEY), saves files, no email
python generate.py               # the full daily job (API + email)
```

Outputs land in `docs/newsletters/<date>/`. Open `docs/index.html` in a browser.

## 🗂️ How it's wired

```
generate.py                 the whole engine (generate → render → archive → email)
sample_quiz.json            canned data for --sample / dry runs
requirements.txt            anthropic, playwright, tzdata
.github/workflows/
  daily-quiz.yml            the cron + manual "Run workflow" job
docs/                       ← GitHub Pages serves this folder
  index.html                archive homepage (regenerated every run)
  style.css, app.js         site design (BLUEPRINT) + tiny theme/quiz JS
  newsletters/<date>/
    index.html              the interactive quiz page
    quiz.pdf                the emailed PDF
    quiz.json               raw quiz data (also drives the archive index)
```

**Flow:** Claude (`claude-opus-4-8`) + the `web_search` tool produce a validated
JSON quiz → rendered to an interactive web page, a Chromium-printed PDF, and an
inline-styled email → saved under `docs/` → emailed via Gmail SMTP → the archive
index is rebuilt → the Action commits and pushes, which refreshes the website.
